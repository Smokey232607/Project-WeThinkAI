 domain model notes


QUESTION 1: What are the 3 main toys (entities)?
ANSWER: Task, Task Priority, Task Status


QUESTION 2: What does Task Priority do?
ANSWER: It's like a volume knob (1-4) that tells us how important a task is.
LOW = 1 (whisper)
MEDIUM = 2 (normal voice)
HIGH = 3 (loud)
URGENT = 4 (screaming!)


QUESTION 3: What does Task Status do?
ANSWER: It's like a board game path that tells us what stage the task is in.
TODO → INPROGRESS → REVIEW → DONE


QUESTION 4: What makes a task "overdue"?
ANSWER: If the due date already passed AND the status is NOT "done".


QUESTION 5: Where do the rules live?
ANSWER: In models.py, inside the Task class.


MY DRAWING:

[Task] --has--> [Priority]

[Task] --has--> [Tags]


GLOSSARY:
• Task = A to-do item
• Priority = Importance level (1-4)
• Status = Current stage (todo, InProgress, review, done)
• Overdue = Late! Past deadline and not finished
• Due Date = The deadline day
• Tags = Labels like stickers
• Created At = Birthday of the task
• Completed At = Exact time the task was finished
